# 🎓 Grade Calculator - Calculadora de Notas UNISINOS

Calculadora premium para estudantes **UNISINOS** com suporte para modalidades **Presencial** e **EAD**.

## 📊 Fórmulas implementadas

| Modalidade | Fórmula | Pesos |
|------------|---------|-------|
| **Presencial** | (Grau A × 1 + Grau B × 2) ÷ 3 | Grau A = Peso 1 / Grau B = Peso 2 |
| **EAD** | (Grau A × 0,3 + Grau B × 0,7) | Grau A = 30% / Grau B = 70% |

## ✨ Funcionalidades

- ✅ Previsão em tempo real do Grau B necessário para aprovação
- ✅ Alerta de Grau C (substitui o Grau B quando necessário)
- ✅ Modo Claro / Escuro com toggle
- ✅ Design responsivo e premium
- ✅ Bloqueio automático de notas fora do intervalo 0-10
- ✅ Resultado visível ao lado, sem precisar rolar a tela
- ✅ Layout em duas colunas totalmente centralizado

## 🖥️ Como usar

1. Selecione a modalidade: **Presencial** ou **EAD**
2. Digite sua nota do **Grau A** (0 a 10)
3. Veja a previsão do quanto precisa no **Grau B**
4. Digite sua nota do **Grau B**
5. Clique em **Calcular Nota Final**
6. O resultado aparece ao lado com sua situação (APROVADO/REPROVADO)

### 📌 Sobre o Grau C

Se você não for aprovado com as notas do Grau A e Grau B, a calculadora informa:
- Se é possível recuperar com o **Grau C**
- Qual nota você precisa tirar no **Grau C** para aprovação
- O Grau C substitui completamente o Grau B no cálculo final

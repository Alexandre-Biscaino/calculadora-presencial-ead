# 🎓 Grade Calculator - Calculadora de Notas

Calculadora premium para estudantes universitários com suporte para modalidades **Presencial** e **EAD**.

## 📊 Funcionalidades

- ✅ **Presencial**: (Grau A × 1 + Grau B × 2) ÷ 3
- ✅ **EAD**: (Grau A × 0,3 + Grau B × 0,7)
- ✅ Previsão em tempo real do Grau B necessário
- ✅ Alerta de Grau C (substitui o Grau B)
- ✅ Modo Claro / Escuro
- ✅ Design responsivo e premium
- ✅ Bloqueio de notas fora do intervalo 0-10
